# Project Brief

## App Name

Weavers Connect – Digital Catalog & Wholesale Inquiry Platform

## Target Users

Handloom artisans, handicraft sellers, wholesale buyers, retailers, and institutional buyers.

## Core Features

1. Categorized product catalog displaying woolens, pashmina products, and wood carvings.
2. Product filtering based on product type and category.
3. Detailed product view with image, material, dimensions, and indicative price.
4. Wholesale inquiry form to collect buyer details, product interest, quantity, and contact information.
5. Integration with Google Sheets for managing buyer inquiries.

## AI Feature Planned

An AI-powered product description generator using the Gemini API. Artisans can enter basic product details, and the system will generate professional product descriptions and marketing content automatically.

## Proposed Tech Stack

Frontend: HTML, CSS, JavaScript, Bootstrap/Tailwind CSS
Backend: Node.js + Express.js
AI API: Google Gemini API
Database: Google Sheets
Deployment: GitHub Pages or Vercel

## Project Overview

This project aims to create a digital catalog platform for the Kumaon Heritage 
Weavers Alliance. The platform will help artisans showcase their products online and 
allow wholesale buyers to browse products remotely without attending exhibitions. 
Buyers can filter products by category and submit wholesale inquiries directly through
the website. Inquiry details will be stored in Google Sheets through a Node.js backend.
The AI-powered description generator will help artisans create professional product descriptions
quickly. The project has a realistic scope for completion within nine weeks and provides a practical 
solution for improving product visibility and buyer engagement.
